# Web

Esta página é o índice das regras de negócio da área `web`. As RNs moram em partes (`web/parte-NN.md`), cortadas por faixa para a página abrir leve; a RN nova entra na ÚLTIMA parte (ADR 0287).

| [parte 3](web/parte-03.md) | RN-239 | 29 | PROGRAMA 28 — Onda 4, frente E2: virtualização de linha e minimapa na aba Code (RN-239..242); PROGRAMA 28 — Onda 4, frente H4: os colapsos ad-hoc restantes migram para o `Disclosure` (RN-249..251); PROGRAMA 28 — Onda 5, frente G3: a tela do Chat RAG (RN-252..254, ADR 0082); UX Designer — o quinto agente conversacional (RN-285..287, ADR 0087); Onda 1 do ADR 0104 — `execution_mode` em três valores, workspace verificado pelo runner; O explorador de pasta do Runner vira três colunas, e a criação de um projeto `runner` deixa de esperar o passo final (RN-436/436); Pasta local anexada vira o quarto escopo do índice RAG, lido pelo NAVEGADOR (RN-455..457, ADR 0113); Painel "precisa de você" (RN-467); Estado de ambiente na tela (RN-468); A seção de Membros respeita o papel, e o papel é o EFETIVO do projeto (RN-471); A pasta vem primeiro, e o binário não é bloqueio (RN-473/474); O `kid` é o vínculo, e a recusa tem nome (RN-475) |
